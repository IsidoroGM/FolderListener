# Ejemplo reproducible

`Proyectos/` contiene dos carpetas, tres archivos vacíos y las salidas reales de
FolderLister en modalidad recursiva, ambos tipos y representación árbol. Los archivos
vacíos solo sirven para generar nombres; sus contenidos no se inspeccionan.

Ejecutar `python scripts/create_example.py` regenera únicamente este ejemplo dentro
del proyecto y autoriza reemplazar sus propias salidas. Las fechas y rutas absolutas
dependen del equipo en que se ejecute. El script no forma parte del menú de la aplicación.
